## Requisitos

- GCC versión 13+ (para soporte de C++23)
- O cualquier compilador moderno que soporte C++23

## Compilación

Para compilar un ejemplo individual:

```bash
g++ -std=c++23 archivo.cpp -o programa
./programa
```

Para compilar todos los ejemplos disponibles:

```bash
chmod +x compilar_todo.sh
./compilar_todo.sh
```

---

## Cómo Usar

1. Revisa los ejemplos en cada carpeta
2. Lee los comentarios en los archivos .cpp
3. Compila y ejecuta los programas
4. Modifica el código para experimentar

Cada archivo tiene comentarios explicativos sobre qué hace el código.
