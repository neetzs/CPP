Exploramos librerías externas y el uso de características del sistema operativo.

## 📝 Instalación de Librerías

```bash
# En Ubuntu/Debian
sudo apt-get install libboost-all-dev

# En macOS con Homebrew
brew install boost
```

## 💡 Conceptos Importantes

- **Thread-safety**: Acceso seguro a recursos compartidos
- **Deadlock**: Cuando threads se bloquean mutuamente
- **Race condition**: Cuando el resultado depende del orden de ejecución

Estos temas son cruciales para aplicaciones modernas.
