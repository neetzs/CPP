# 00 - Fundamentos de C++

En esta sección vamos a aprender los conceptos básicos de C++.

## 📌 Temas a Cubrir

### 1. **Hola Mundo** - Tu primer programa
- Estructura básica de un programa C++
- main() - función principal
- cout - salida en pantalla

### 2. **Variables y Tipos de Datos**
- int, float, double, bool
- char y strings
- Declaración y inicialización
- const y variables

### 3. **Operadores**
- Aritméticos: +, -, *, /, %
- Comparación: ==, !=, <, >, <=, >=
- Lógicos: &&, ||, !
- Asignación: =, +=, -=, etc.

### 4. **Entrada y Salida**
- cin - entrada del teclado
- cout - salida a pantalla
- getline() - lectura de líneas completas

### 5. **Estructuras de Control**
- if, else if, else
- switch
- while, do-while
- for (clásico e iterador)

## 📝 Estructura de Aprendizaje

```
Hola Mundo
    ↓
Variables y Tipos
    ↓
Operadores
    ↓
Entrada/Salida
    ↓
Estructuras de Control
```

## 🎯 Objetivos al Finalizar esta Sección

- [ ] Entender cómo compilar y ejecutar programas C++
- [ ] Conocer los tipos de datos básicos
- [ ] Manejar entrada y salida con cin/cout
- [ ] Usar estructuras de control (if, for, while)
- [ ] Escribir programas simples e interactivos

## 💡 Tips Importantes

1. **Indentación**: Mantén tu código indentado para que sea legible
2. **Punto y coma**: Cada sentencia debe terminar con `;`
3. **Llaves**: Los bloques se rodean con `{ }`
4. **Comentarios**: Usa `//` para comentarios de una línea, `/* */` para múltiples
