# 04 - Programación Orientada a Objetos (POO) - Nivel Avanzado

Aquí profundizamos en conceptos avanzados de POO para crear arquitecturas complejas.

## Temas a Cubrir

### 1. **Herencia**
- Clase base y clase derivada
- Herencia simple y múltiple
- Reutilización de código

### 2. **Polimorfismo**
- Métodos virtuales
- Sobrescritura de métodos
- Polimorfismo en tiempo de ejecución

### 3. **Clases Abstractas**
- Métodos puramente virtuales
- Interfaces
- Contratos de clases

### 4. **Sobrecarga**
- Sobrecarga de operadores
- Sobrecarga de funciones
- Operadores especiales: `+`, `-`, `[]`, `()`

### 5. **Miembros Estáticos**
- Variables de clase (compartidas)
- Métodos de clase
- Diferencia con instancia

## Objetivos al Finalizar

- [ ] Implementar herencia correctamente
- [ ] Usar polimorfismo eficientemente
- [ ] Crear clases abstractas
- [ ] Sobrecargar operadores y funciones
- [ ] Usar miembros estáticos

## Estructura de Aprendizaje

```
Herencia
    ↓
Polimorfismo
    ↓
Clases Abstractas
    ↓
Sobrecarga
    ↓
Miembros Estáticos
```

## Importante

En C++ moderno, prefiere **composición sobre herencia** cuando sea posible.
