# 01 - Funciones y Modulares

En esta sección aprenderemos cómo **organizar y estructurar nuestro código** usando funciones, parámetros, y namespaces.

## 📌 Temas a Cubrir

### 1. **Funciones Básicas**
- Definir y llamar funciones
- Parámetros
- Retorno de valores

### 2. **Paso de Parámetros**
- Por valor (copia)
- Por referencia (modifica original)
- Por puntero

### 3. **Retorno de Valores**
- Diferentes tipos de retorno
- Retorno múltiple (en estructuras/tuplas)

### 4. **Recursión**
- Funciones que se llaman a sí mismas
- Casos base y recursivos

### 5. **Namespaces**
- Organización de código
- Evitar conflictos de nombres
- Namespaces anidados

## 🎯 Objetivos al Finalizar

- [ ] Escribir y llamar funciones correctamente
- [ ] Entender la diferencia entre parámetros por valor y referencia
- [ ] Implementar funciones recursivas
- [ ] Usar namespaces para organizar código
- [ ] Modularizar código en funciones

## 📝 Estructura de Aprendizaje

```
Funciones Básicas
    ↓
Paso de Parámetros
    ↓
Retorno de Valores
    ↓
Recursión
    ↓
Namespaces
```

## 💡 Tips Importantes

1. Una función debe tener un propósito claro
2. Usa nombres descriptivos para funciones: `calcularPromedio()`, `validarEdad()`
3. Divide problemas grandes en funciones pequeñas
4. Las funciones hacen el código más legible y reutilizable
