# 99 - Proyectos Integradores

En esta sección, aplicarás TODO lo que has aprendido en **proyectos prácticos y completos**.

## Proyectos

### 1. **Calculadora** ⭐ Básico
**Objetivos:**
- Entrada/salida
- Operadores
- Estructuras de control
- Funciones

**Características:**
- Operaciones básicas: +, -, *, /
- Menú interactivo
- Validación de entrada

### 2. **Gestor de Tareas** ⭐⭐ Intermedio
**Objetivos:**
- Contenedores (vector)
- Clases y objetos
- Archivos
- Estructuras

**Características:**
- Agregar, eliminar, completar tareas
- Guardar/cargar desde archivo
- Listar tareas
- Marcar como completadas

### 3. **Sistema de Personas** ⭐⭐⭐ Intermedio-Avanzado
**Objetivos:**
- POO completo
- Herencia y polimorfismo
- Contenedores complejos
- Archivos

**Características:**
- Clase Persona (nombre, edad, etc.)
- Subclases: Estudiante, Profesor
- Búsqueda y filtrado
- Persistencia en archivos

### 4. **Simulación Compleja** ⭐⭐⭐⭐ Avanzado
**Objetivos:**
- Todo lo anterior
- Algoritmos complejos
- Optimización
- Manejo de errores

**Características:**
- Sistema solar o ecosistema virtual
- Múltiples entidades interactuando
- Visualización en texto
- Parámetros configurables

## Metodología

Para cada proyecto:

1. **Lee la descripción completa**
2. **Entiende los requisitos**
3. **Diseña la estructura**
4. **Implementa paso a paso**
5. **Prueba y depura**
6. **Refactoriza si es necesario**

## Estructura de cada Proyecto

```
01-Calculadora/
├── README.md (descripción completa)
├── requisitos.txt (lista de requisitos)
├── main.cpp (punto de entrada)
├── calculadora.h (header)
├── calculadora.cpp (implementación)
└── ejemplos/ (ejemplos de uso)
```

## Tips para Proyectos

- ✅ Comienza simple, agrega complejidad
- ✅ Usa Git para controlar cambios
- ✅ Divide en módulos reutilizables
- ✅ Comenta tu código
- ✅ Prueba con casos extremos
- ✅ Maneja errores correctamente
