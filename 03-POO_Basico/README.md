# 03 - Programación Orientada a Objetos (POO) - Nivel Básico

**POO** es un paradigma de programación que organiza el código en objetos (entidades con propiedades y comportamiento).

## 📌 Temas a Cubrir

### 1. **Clases y Objetos**
- Definición de clases
- Creación de objetos
- Miembros: atributos y métodos

### 2. **Constructores y Destructores**
- Constructor: inicializa el objeto
- Destructor: limpia recursos

### 3. **Atributos y Métodos**
- Propiedades (atributos)
- Acciones (métodos)
- Método `this`

### 4. **Encapsulamiento**
- `private`: acceso solo desde la clase
- `public`: acceso desde cualquier lugar
- `protected`: para herencia

### 5. **Getters y Setters**
- Acceso controlado a atributos
- Validación de datos

## 🎯 Objetivos al Finalizar

- [ ] Crear clases y objetos
- [ ] Entender constructores/destructores
- [ ] Implementar encapsulamiento
- [ ] Usar getters y setters
- [ ] Aplicar OOP a problemas reales

## 📝 Estructura de Aprendizaje

```
Clases y Objetos
    ↓
Constructores/Destructores
    ↓
Atributos y Métodos
    ↓
Encapsulamiento
    ↓
Getters y Setters
```

## 💡 Conceptos Clave

**Clase** = Plano, molde
**Objeto** = Instancia, realización del plano

Ejemplo: Clase "Coche" → Objetos: "Mi Toyota", "Tu Ford"
